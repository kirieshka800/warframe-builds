# Ручная проверка

Проверяйте на тестовых билдах. Кнопки «Применить» и «Сохранить полярность» сразу
сохраняют изменения; удаление требует подтверждения.

1. **Профиль:** создать локальный профиль, открыть «Мои билды». В другом браузере
   создать профиль с тем же именем: прежние записи не должны стать редактируемыми.
2. **Варфрейм:** создать Rhino, установить Vitality ранга10 в обычный слот,
   сменить полярность на Vazarin. Стоимость уменьшается с округлением вверх.
   После обновления страницы мод, ранг и полярность остаются.
3. **Вместимость:** Forma сама по себе не добавляет очки. Реактор меняет30 на60.
   Аура Corrosive Projection ранга5 добавляет7 очков без полярности и14 при совпадении.
   Расход нельзя увеличить сверх вместимости; нельзя убрать ауру, если это создаст
   переполнение. Сначала уберите или понизьте обычные моды.
4. **Совместимость:** Vitality не устанавливается в эксилус. Aura — только в слот
   ауры, для оружия недоступна. Один мод и его альтернативная версия не складываются.
5. **Винтовка:** создать Braton, установить Serration. Показаны оружейные
   характеристики, аура отсутствует. После смены ранга урон меняется.
6. **Пистолет/ближний бой:** создать Lato и Skana. У пистолета своя группа модов;
   у Skana доступна совместимая стойка Iron Phoenix, добавляющая вместимость.
7. **Обмен:** скопировать ссылку и открыть без входа — можно читать, нельзя менять
   оригинал. После входа «Создать копию» создаёт собственную редактируемую сборку.
8. **JSON:** экспортировать, импортировать через каталог. Слоты/ранги/полярности
   совпадают. Повреждённый JSON, повтор слотов или недопустимый ранг не создают билд.
9. **Гайды/комментарии:** создать гайд, изменить и удалить его своим профилем.
   Чужой профиль не может это сделать. Вставленный HTML показывается текстом.
10. **Каталог:** поиск по имени, фильтры типов, «Мои билды» и пагинация. Запустить
    обновление справочника; при сетевой ошибке старые записи доступны.
11. **Телефон:** при390px открыть главную, создание, редактор и справочник.
    Нет горизонтального скролла страницы, формы и кнопки доступны.
12. **Удаление:** отменить подтверждение — билд остаётся. Подтвердить — исчезает,
    комментарии удаляются вместе с ним. Чужую запись удалить нельзя.

Проверка настоящего Steam выполняется вручную в браузере с доступом к Steam.
Пароль Steam вводится только на steamcommunity.com.
