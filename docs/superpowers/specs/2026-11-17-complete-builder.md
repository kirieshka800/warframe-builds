# Доработка WarframeBuilds

Пользователь поручил довести исходный сайт до рабочего состояния и разрешил полезные
дополнения; уточнил обязательную поддержку варфреймов и оружия. Сохраняем ASP.NET
Core10 MVC и PostgreSQL, расширяем исходную модель Build вместо создания другого сайта.

Цель: выбрать снаряжение, настроить совместимые моды/ранги/полярности, видеть
вместимость и базовые характеристики, сохранить, редактировать свою сборку и поделиться.
Статистика — планировщик от баз каталога, не полная симуляция боя; неизвестные и
условные эффекты отмечаются. Forma не увеличивает вместимость. Спецслоты добавляют
вместимость, обычные расходуют; ранги/дубликаты/совместимость проверяются сервером.

Доступ: проверенный Steam OpenID через middleware или отдельный случайный локальный
профиль в cookie. Имена не определяют владельца. Локальный профиль без восстановления
после потери cookie; для переноса доступны JSON и Steam. Все изменения требуют
входа и antiforgery. Существующие бесхозные билды/гайды сохраняются для чтения.

Полезные дополнения: публичный каталог, фильтры/пагинация, копия чужого билда,
JSON-импорт/экспорт, комментарии, гайды, стартовые данные без сети и ручной импорт WFCD.
Старые данные мигрируют добавочно; оригинальные строки слотов архивируются перед
исправлением ошибочного составного ключа. Нет перезаписи реальной базы в тестах.

Проверки: автономные расчёты, реальные HTTP+PostgreSQL, браузерные сценарии обоих
типов снаряжения, мобильная ширина, обновление существующей базы. Результат — архив
исходников с README и Docker/local инструкцией; публикация в старый Rust-репозиторий
не относится к этой задаче и не выполняется.
