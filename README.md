# Tenno Lab · Warframe Builds

Сайт для создания и обмена билдами **варфреймов и оружия**. ASP.NET Core10 MVC,
Entity Framework Core и PostgreSQL. Интерфейс на русском, работает на телефоне.

## Что работает

- Конструктор варфреймов, основного/вторичного оружия и ближнего боя.
- Совместимые моды, выбор ранга, обычные слоты, аура/стойка, эксилус и полярности.
- Вместимость30/60, бонус ауры/стойки, ограничения рангов и альтернативных модов.
  Forma не добавляет вместимость: она позволяет менять полярность.
- Базовые характеристики с эффектами выбранного ранга; особые/условные эффекты
  отмечаются в примечаниях расчёта.
- Создание и изменение своих билдов, удаление с подтверждением, публичный каталог,
  поиск, фильтры, пагинация, создание собственной копии чужого билда.
- Настоящая ссылка на билд, экспорт/импорт JSON, комментарии.
- Справочник снаряжения и модов, гайды с созданием/редактированием своих материалов.
- Вход через Steam либо отдельный локальный профиль браузера.
- Стартовые8 варфреймов,10 единиц оружия,57 модов и3 гайда без сетевой загрузки.
  Каталог можно расширить из WFCD кнопкой «Обновить каталог» в справочнике.

## Быстрый запуск с Docker Desktop

Понадобятся Docker Desktop и интернет для первой загрузки образов/пакетов.
В терминале откройте папку с `compose.yaml`:

```sh
docker compose up --build
```

После запуска откройте **http://localhost:5026**. База создаётся, миграции и
стартовый каталог применяются автоматически. Для остановки нажмите Ctrl+C,
затем `docker compose down`. Данные остаются в именованных томах.
`docker compose down -v` удаляет данные — не используйте эту команду для обычной остановки.

В `.env.example` указан пароль только для локальной разработки. При необходимости
скопируйте файл в `.env` и смените `DB_PASSWORD` **до первого запуска новой базы**.
Смена переменной после создания тома сама по себе не меняет пароль в PostgreSQL.
Контейнер сайта привязан к127.0.0.1; публичное размещение требует отдельной настройки.

## Запуск без Docker (Windows / Visual Studio / Rider)

1. Установите **.NET10 SDK**: https://dotnet.microsoft.com/download/dotnet/10.0
   и **PostgreSQL17 или18**. Visual Studio должна поддерживать .NET10.
2. В pgAdmin создайте пустую базу `WarframeBuildsDb`.
3. В PowerShell из папки с `WarframeBuilds.sln` задайте строку подключения:

```powershell
$env:ConnectionStrings__DefaultConnection = 'Host=localhost;Port=5432;Database=WarframeBuildsDb;Username=postgres;Password=ВАШ_ПАРОЛЬ'
dotnet restore WarframeBuilds/WarframeBuilds.csproj
dotnet run --project WarframeBuilds --urls http://localhost:5026
```

В macOS/Linux используйте `export ConnectionStrings__DefaultConnection='...'`.
При открытии решения в IDE задайте ту же переменную окружения в конфигурации запуска.
Пароль не нужно записывать в исходники. `appsettings.json` содержит адрес без пароля:
переменная окружения переопределяет его. `.env` читается Docker Compose, но не `dotnet run`.
Первое восстановление NuGet требует интернета. Сам сайт и стартовый каталог работают
без загрузки WFCD; картинки с CDN и Steam требуют сети.

## Автоматически подобрать билд

Нажмите **«Подобрать билд»** в каталоге, на главной или на странице создания.
Выберите варфрейм/оружие, цель, наличие реактора и максимум форм0–8.
Для варфреймов доступны баланс, выживаемость, сила, длительность, радиус и
энергоэффективность; для оружия — баланс, критический урон и статус.

Сначала появится **предложение**: моды, ранги, полярности, вместимость,
базовые характеристики и объяснение выбора. До нажатия
**«Подтвердить и сохранить»** билд в БД не создаётся. После подтверждения
откроется обычный редактор. «Отменить предложение» не создаёт запись.
Повторное подтверждение активного предложения возвращает тот же результат.

Подбор работает **по правилам без AI-сервера**. Он использует распространённые
моды из каталога сайта, не знает ваш игровой инвентарь и не гарантирует мета-билд.
Исходные полярности считаются нейтральными: текущий каталог не хранит полярности
слотов конкретного предмета. Количество реально изменённых полярностей не
превышает выбранный лимит форм. При неполном каталоге предложение может иметь
незаполненные слоты; сайт объяснит это и не позволит сохранить пустой билд.

Предпросмотр привязан к профилю и хранится на сервере15минут. При перезапуске
сервера или вытеснении старого предпросмотра из ограниченного кеша потребуется
повторить подбор. Изменение данных выбранных модов/предмета в каталоге также
требует нового предложения: другие параметры не сохраняются молча.

## Первый билд

1. Нажмите «Создать билд». Создайте локальный профиль или войдите через Steam.
2. Выберите тип снаряжения, конкретный предмет, название и реактор/катализатор.
3. Откройте «Установить мод» нужного слота. Найдите мод, выберите ранг и нажмите
   «Применить». Отдельная кнопка сохраняет полярность. Изменения сразу пишутся в БД.
4. Проверьте вместимость и характеристики. Для варфрейма можно добавить ауру,
   для ближнего боя — совместимую стойку. Эксилус принимает только подходящие моды.
5. Скопируйте ссылку: другой человек увидит билд без права изменить оригинал.
   После входа он сможет создать собственную копию.
6. «Настройки» меняют название, описание, реактор и заметку о Гельминте.
   Для другого предмета создайте новый билд: установленные моды не переносятся молча.

**Локальный профиль** хранится в защищённой cookie этого браузера до90 дней
с продлением при использовании. Это не Steam-аккаунт и не парольный аккаунт.
После выхода или удаления cookie доступ к прежнему локальному профилю потеряется;
публичные билды останутся доступны для копирования. Для доступа с разных устройств
используйте Steam, для резервной копии — экспорт JSON. Одинаковые имена профилей
не объединяют их права. В конфигурации `Authentication:AllowLocalProfiles=false`
можно отключить создание локальных профилей.

## Каталог и точность расчётов

Стартовая подборка встроена в приложение. Обновление в разделе «Арсенал» загружает
Warframes, Mods, Primary, Secondary и Melee из публичного проекта
[WFCD/warframe-items](https://github.com/WFCD/warframe-items). Записи обновляются
на месте, существующие ссылки модов и предметов не удаляются. Повторное обновление
не должно создавать дубликаты. При сетевой ошибке доступен уже загруженный каталог.
Полное обновление занимает время; кнопка защищена от параллельных запусков.
Его можно отключить через `Catalog:AllowSync=false`.

**Это планировщик, не полный симулятор Warframe.** Характеристики считаются от
базовых значений каталога. Рост по рангу, пассивные способности, сопротивления,
броня противника, проки/реакции статусов, комбо, условные усиления, отдельные режимы
огня и множество особых взаимодействий не моделируются. Значения эффектов берутся
из `levelStats` выбранного ранга, неподдерживаемые эффекты перечислены в примечаниях.
Урон показан за попадание до сопротивлений, а не как универсальный DPS.
Неизвестная совместимость не разрешается автоматически. У отдельных предметов
метаданные источника неполные — сверяйте спорные случаи с игрой.
Заметка о Гельминте сохраняется как текст и не меняет формулы способностей.

## Обновление существующей базы

Сначала сделайте резервную копию PostgreSQL. Старые миграции сохранены, новая
`CompleteBuilder` применяется автоматически при старте. Она добавляет оружие,
комментарии и метаданные; исправляет ключ `BuildMods`, чтобы пустые поляризованные
слоты действительно сохранялись. Сохраняются тексты, билды и идентификаторы предметов.
Оригинальные строки слотов перед исправлением копируются в `LegacyBuildModsBackup`.
Если в старой базе было несколько модов в одном слоте, активной остаётся одна строка,
остальные доступны в этой резервной таблице. Идентификаторы строк слотов нормализуются.

Старые билды/гайды без достоверного идентификатора владельца доступны для чтения
и копирования, но их нельзя присвоить простым совпадением ника. Метаданные стартовых
предметов дополняются автоматически; остальные старые моды могут потребовать
обновления каталога. Обратная миграция после создания оружейных билдов не предусмотрена
как способ восстановления: используйте резервную копию.

## Если что-то не работает

- **Нет подключения к БД:** убедитесь, что PostgreSQL запущена, база существует,
  порт/пользователь/пароль совпадают со строкой. Подключение в pgAdmin под другим
  пользователем не подтверждает правильность пароля приложения.
- **Порт5026 занят:** остановите старую копию либо используйте другой порт в `--urls`.
- **Нет модов для слота:** проверьте тип предмета, эксилус/ауру/стойку и поисковую
  строку. Некоторые предметы имеют ограниченные метаданные совместимости.
- **Не удаётся убрать ауру:** сначала освободите достаточно вместимости обычных
  слотов. Сохранение заведомо более переполненной конфигурации блокируется сервером.
- **Steam не открывается:** проверьте сеть и доступ к steamcommunity.com. Реальный
  вход идёт через проверенный OpenID middleware; подставлять SteamID вручную не нужно.
- **Сессии пропадают после развёртывания:** сохраните папку `App_Data/Keys` и том
  `app-keys`. Это ключи подписи cookie. В публичном размещении защитите их права,
  настройте HTTPS, доверенный reverse proxy и конкретные `AllowedHosts`.

## Проверки и структура

```sh
dotnet build WarframeBuilds/WarframeBuilds.csproj
dotnet run --project tests/CalculationChecks
dotnet run --project tests/AutoBuildChecks
```

Для интеграционных сценариев нужен **отдельный тестовый экземпляр сайта и базы**:
тесты создают профили/билды/гайды. Python-проверкам нужен пакет Playwright и Chromium.

```sh
python -m pip install playwright
python -m playwright install chromium
# WARFRAME_TEST_URL=http://127.0.0.1:5026
python tests/http_checks.py
python tests/browser_checks.py
python tests/auto_build_http.py
python tests/auto_build_browser.py
```

При необходимости задайте `CHROMIUM_PATH` — путь к Chromium; в проверочной среде
использовался `/usr/bin/chromium`. Итоги проверок: [docs/VERIFICATION.md](docs/VERIFICATION.md).
Ручные сценарии: [docs/TESTING.md](docs/TESTING.md).

`WarframeBuilds/` — исходный MVC-проект; `Services/` — расчёты/совместимость/каталог;
`Migrations/` — обновления БД; `Views/` и `wwwroot/` — интерфейс; `tests/` — проверки.
Warframe — торговая марка Digital Extremes. Проект не является официальным сервисом.
